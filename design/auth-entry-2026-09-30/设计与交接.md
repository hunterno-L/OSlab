# OSLab 注册登录入口：设计与动效交接

## 1. 设计目标

做一张大气、克制、有流动感的教学平台入口。用户在登录前能理解平台的学习方式，同时能迅速完成登录或注册。主要视觉特征是白色开放场景、精确的中文排版、连续的知识路径和清晰的表单。

本轮交付包含登录效果图、注册效果图、循环动图和可交互的设计预览。平台正式实现由接手 agent 完成，当前 Vue 页面未被修改。

## 2. 构图与内容

整页是连续的近白场景。左侧品牌、简介和知识流自然衔接，右侧登录表单直接放置在页面上，不做浮动卡片。上下内容共用对齐线。

桌面效果图基准为 1600 × 1000，高清图为 3200 × 2000。品牌内容从 x=112 开始，表单从 x=1090 开始，表单宽 386；实际实现使用响应式网格，不锁死这些绝对坐标。

### 登录

表单标题为“继续你的学习”。字段为账号、密码；操作为显示/隐藏密码、记住账号、登录。登录与注册使用同一场景的页签切换。

### 注册

表单标题为“创建你的学习账号”。字段为账号、密码、确认密码。提示为“账号至少 4 位，密码至少 8 位。”主按钮为“创建账号”。

切换模式保留账号输入，清空密码与确认密码。第一版按现有账号接口实现。

## 3. 视觉参数

参考 OpenDesign 提供的 Mistral 中性色、4px 间距节奏和细边界，延续前一轮克制的排版方向。中文字体和动效是本平台的独立适配。

| 参数 | 值 |
| --- | --- |
| 页面底色 | `#FAFAF8` |
| 正文主色 | `#171A1D` |
| 次级正文 | `#525962` |
| 辅助文字 | `#777F86` |
| 边界 | `#DADFE3` |
| 品牌蓝 | `#2059C9` |
| 少量知识状态色 | `#4F8875` |
| 表单与主按钮圆角 | `6px` |
| 字距 | `0` |
| 正文行高 | `1.7–1.9` |
| 间距节奏 | `4 / 8 / 12 / 16 / 24 / 32 / 48 / 64px` |

中文使用 PingFang SC / Microsoft YaHei，西文标题使用 Segoe UI 或本机无衬线字体。标题、正文、数字之间需要有明确层级，优先根据效果图匹配比例。使用固定字号的断点调整。

主按钮采用墨色；蓝色集中用于当前页签、输入焦点和知识信号。简介区靠标题、细线与留白形成质感。原有标识保留其酒红和橙色。

## 4. 动态炫技：知识流

主视觉是一组 2D 贝塞尔曲线构成的连续知识路径：

```text
虚拟内存 → 页表 → 缺页中断 → LRU
               ↘ 地址转换      ↗ 页面置换实验
```

这是一段课程路径示意，与个人实时掌握度无关。避免将登录前的示意画面表达成真实学生状态。

### 空闲状态

25 条细线以不同纵向偏移组成弯曲带状路径；每条线约 0.65–0.9px。两段蓝色短光流沿路径持续推进，形成局部高亮，不把整条背景染蓝。

一个完整循环为 8.4 秒。曲线本身只做约 1.5px 的细微漂移，节点文字稳定。光流接近节点时，节点细环扩展约 6px，内点短暂变蓝，随后回到墨色。

### 指针响应

指针在知识流区域移动时，图形做最大约 5px 横向、3px 纵向的位移，缓动系数约 0.06。表单与文字保持稳定。

### 输入焦点

任一表单字段获得焦点后，流速降至空闲状态的 35%。失去焦点后回到正常速度。输入边界用 180ms 过渡到品牌蓝。

### 登录与注册切换

- 页签下划线移动：240ms。
- 确认密码字段高度展开/收起：280ms。
- 字段透明度配合变化：180ms。
- 缓动使用 `cubic-bezier(.2,.7,.2,1)`。

品牌、介绍和知识流不在切换时重新加载。密码字段收起后离开键盘焦点顺序。

### 提交

实际实现以 API 状态驱动按钮 loading。注册成功回到登录并保留账号；登录成功进入原目标页面。可在成功后让知识流向前推进一小段再切换路由，总额外延迟不超过 200ms。

交互预览里的按钮只演示约 1.1 秒的忙碌状态，不发送账号请求；接手 agent 应替换为实际 API 的 loading 状态。

### 移动端与动效控制

740px 以下采用品牌 → 缩短的知识流 → 表单 → 简介的纵向顺序。输入字号保持 16px，按钮高度至少 48px。后台或离开视口时暂停绘制；尊重 `prefers-reduced-motion`，提供“暂停动效”控件。

## 5. 接手 agent 的代码落点

以下文件及接口已在本次设计中只读核对：

| 文件 | 执行动作 |
| --- | --- |
| `前端代码/osLab-frontend/src/layouts/UserLayout.vue` | 按效果图替换现有认证页面壳，放置平台简介与知识流 |
| `前端代码/osLab-frontend/src/views/user/UserLoginView.vue` | 保留现有登录服务与状态逻辑，按设计重排表单 |
| `前端代码/osLab-frontend/src/views/user/UserRegisterView.vue` | 保留账号、密码、确认密码校验，按设计重排注册表单 |
| `前端代码/osLab-frontend/src/components/auth/AuthFlowCanvas.vue` | 新建知识流组件，参考 `auth-flow.html` 中的曲线与动画实现 |
| `前端代码/osLab-frontend/src/assets/oj-logo.svg` | 直接使用原始标识 |
| `前端代码/osLab-frontend/src/access/index.ts` | 对接已经传入的 `redirect` 查询参数 |
| `前端代码/osLab-frontend/generated/services/UserControllerService.ts` | 直接调用现有方法，不手工改生成文件 |

现有服务方法：

```text
UserControllerService.userLoginUsingPost({ userAccount, userPassword })
UserControllerService.userRegisterUsingPost({ userAccount, userPassword, checkPassword })
```

成功判断沿用 `res.code === 0`；登录后刷新 Vuex 的 `user/getLoginUser`。当前路由守卫会传递 `/user/login?redirect=...`，登录页目前固定跳转 `/`，本次正式实现应使用有效的站内目标路径，无目标时进入 `/`。

记住账号沿用 `oslab:remember-account`，只保存账号。注册沿用现有至少 4 位账号、8 位密码以及两次密码一致的校验。

## 6. 实施顺序

1. 先按照静态图做页面网格、品牌区和登录注册表单，复用现有真实账号流程。
2. 将知识流从预览中移植为 Vue 组件，先完成静止画面，再接入统一的 `requestAnimationFrame` 时间轴。
3. 接入光流、节点响应、焦点减速和模式切换，调至效果图中约定的强度。
4. 做窄屏布局，检查账号长文本、注册错误提示和提交 loading 的空间。
5. 接入 `redirect`、注册成功回登录和错误反馈，完成实际账号验证。
6. 输出前端构建结果、桌面/移动端截图及一次真实登录注册的验收记录。

## 7. 验收

- 首屏可读到产品名、平台简介和账号入口。
- 登录/注册模式切换不使整个页面跳动，确认密码能展开并正常作答。
- 信号连续流动且沿知识关系走，节点文字不会漂移；输入焦点时动效明显减速。
- 登录、注册、显示密码、记住账号和原目标页面跳转使用真实现有流程。
- 1440、1024、390、360px 下文字与输入不相互覆盖；手机端可以完整滚动至表单和简介。
- 成功、失败和 loading 有可见状态，前端 `npm run build` 通过。
