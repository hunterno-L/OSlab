# OSLab 前端视觉方案 A

四张静态页面效果图，供人工审核视觉方向与信息布局。页面中的学习记录和班级统计均为设计示例，不代表当前平台已实现对应功能。

采用浅色学习工作台、深色知识图谱画布和青绿色强调色。普通题、编程实验、算法模拟与掌握度围绕同一条学习路径组织。

| 文件 | 页面 | 核心内容 |
| --- | --- | --- |
| `00-overview.png` | 四图总览 | 对照整套视觉风格与页面衔接 |
| `01-knowledge-graph.png` | 个人知识图谱 | 前置路径、掌握状态、证据与下一步练习 |
| `02-knowledge-practice.png` | 知识点练习 | 判断、单选、多选、填空入口，判分反馈与概念卡 |
| `03-algorithm-lab.png` | 页面置换实验室 | FIFO/LRU/OPT、逐步内存状态、下一步预测 |
| `04-teaching-insights.png` | 教师看板 | 班级知识热力、薄弱点、事件与教学建议 |

单页原图为 3200 × 2080 PNG，`-preview.png` 为较小的预览版。效果图由本目录 `render_mockups.py` 使用 Pillow 直接渲染，无浏览器依赖。

本轮先审核页面效果，再据此完善详细执行计划。可重点反馈整体风格、信息密度、图谱表现方式以及练习页是否顺手。

重新生成：在装有 Pillow 的 Python 环境运行 `python render_mockups.py`。
