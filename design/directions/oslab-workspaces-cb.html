从人工控制转向自动控制

操作系统发展历程 · 版本 1 · 1.2.1 / 1.2.2 引言 · PDF 19–19 · 7 NODES

手工阶段没有操作系统，用户独占主机并人工安排装入、运行和输出。虽然不必等待其他用户释放资源，机器整体利用率却很低，CPU 要等待人的慢速操作。

硬件越快，人机速度差距越突出。批处理以机器自动控制作业，试图同时缓解人机矛盾和 CPU 与 I/O 速度不匹配的问题。

任务描述

在 MIPS CPU 中，内存管理以 4KB 大小为单位，称为页。为了记录内存分配情况，需要使用 Page 结构体来记录一页内存的相关信息。本实验要求学生理解并实现链表操作宏函数，以便在内存管理中高效地进行页的插入和尾部添加操作。

知识要点

MIPS CPU 内存管理数据结构宏函数C 语言编程

实验任务

①
理解 Page 结构体

理解 pp_link 和 pp_ref 的作用；掌握 LIST_ENTRY(Page) 的定义和用途。

②
阅读和理解宏函数

阅读 include/queue.h 中定义的宏函数，特别注意 do { ... } while(0) 的写法。

③
实现两个链表宏

LIST_INSERT_AFTER 与 LIST_INSERT_TAIL，在右侧编辑器中完成指针重连。

先读 queue.h 里的宏写法，再动指针；页的插入顺序错了，TLB 实验会连带失败。
