# 操作系统实验室 - 服务器部署指南

## 部署架构

```
用户浏览器
    ↓
Nginx (反向代理)
    ├── /          → 前端静态文件
    └── /api       → 后端服务 :8121
    ↓
后端服务 (Spring Boot)
    ├── MySQL      → 数据存储
    ├── Redis      → 缓存/Session
    └── Neo4j      → 知识图谱
```

## 服务器要求

- 操作系统: Ubuntu 20.04+ / CentOS 7+ / Windows Server
- CPU: 2核+
- 内存: 4GB+
- 磁盘: 20GB+

## 快速部署

### 方式一：Docker 部署（推荐）

```bash
# 1. 安装 Docker 和 Docker Compose
curl -fsSL https://get.docker.com | sh
sudo usermod -aG docker $USER

# 2. 上传项目到服务器
scp -r 源程序（包含数据库） user@server:/opt/oslab

# 3. 进入目录并启动
cd /opt/oslab
docker-compose up -d

# 4. 查看状态
docker-compose ps
```

### 方式二：手动部署

```bash
# 1. 安装依赖
./install-dependencies.sh

# 2. 配置数据库
./setup-database.sh

# 3. 构建并启动
./deploy.sh
```

## 访问地址

部署完成后：
- 前端: http://your-server-ip
- 后端 API: http://your-server-ip/api
- API 文档: http://your-server-ip/api/doc.html

## 端口说明

| 端口 | 服务 | 外网访问 |
|------|------|---------|
| 80 | Nginx | ✅ 开放 |
| 443 | Nginx (HTTPS) | ✅ 开放 |
| 8121 | 后端服务 | ❌ 仅内网 |
| 3306 | MySQL | ❌ 仅内网 |
| 6379 | Redis | ❌ 仅内网 |
| 7687 | Neo4j | ❌ 仅内网 |
