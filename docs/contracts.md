# 课程与学习数据约定

本文记录维护所需的当前约定。实际请求与字段以源码 DTO、服务端校验和开发环境 API 文档为准，不依赖旧批次任务书。

## 稳定身份

- `courseCode` 表示课程，`sectionCode` 表示目录小节，`unitCode` 表示学习单元，`activityCode` 表示单元活动。
- `nodeCode` 是稳定知识节点代码；显示名称可以改变，身份代码不随标题更换。历史图库 ID 由服务端身份解析兼容。
- 数据库长整型 ID 在 JSON、路由和内容包中用字符串保存，不在 JavaScript 中转成 `Number`。
- 教师任务、单元和活动来源随作答或实验提交传递，避免离开当前场景后丢失归属。

## 内容包

知识、题目、单元和实验维护包分别存放在 `content/` 对应目录。知识需要正文、来源及节点关联；题目需要题干、类型、答案或评分点、解析与关联节点；单元需要目标、资料、活动与顺序。批次、修订及审核状态由后台维护，内容修改须经过预览、校验、审核与发布。

综合应用题保留参考答案和评分点，不将其当作普通客观题自动评分。图片引用须能定位实际资源，不使用开发者本机绝对路径作为线上地址。样例、草稿与正式发布数据分开处理。

## 实验

实验维护包包含题目稳定身份、正文、初始代码、参考实现、测试用例、判题限制及节点/单元映射。源码和用例通过校验后，由管理员在教师内容入口接收。

| 模式 | 行为 |
| --- | --- |
| `AUTO` | 在真实隔离沙箱中运行测试 |
| `CONCEPT_HARNESS` | 在线验证有限概念；通过不表示完成完整系统构建 |
| `LOCAL_BUILD` | 必须在配套本地环境执行，在线自动判分被禁用 |

测试程序需覆盖初始、正确参考、已知错误三个版本。不能仅以“参考实现通过”证明用例有效。

## 学习证据与导师

作答、实验与来源上下文由服务端保存。即时反馈和整组自测使用不同展示节奏；幂等提交不重复累计首次观测。已看答案、系统故障等会影响证据资格，不由 AI 自行决定。

课程范围来自已启用且已发布的内容；画像、推荐、路径和导师工具按该范围裁剪。无有效范围返回空结果或明确拒绝，不回退成全站数据。禁用课程的新操作被拒绝，历史 AI 会话仍可只读查看。

全局与场景导师共享课程会话，页面入口可以改变辅导模式和上下文。教师导师只预填班级汇总，教师明确发送后才调用模型。模型、embedding 或工具不可用时返回实际降级状态，保留引用和工具执行来源供检查。

## 教师任务

教师查询绑定有权限的班级，任务对象支持班级与个人。发布时固定题目、实验及评分规则的快照；批阅时使用发布版本。班级统计只统计当前班级成员，各类跟进人数可能重叠。附件通过权限接口读取，不放在前端公开目录。
