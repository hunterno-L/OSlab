### C2 沙箱判题契约（`代码沙箱/server.py`、`runner.py` 实测）
- 语言仅 `java`/`c`/`cpp`/`go`。C 走 `gcc -O2 -pipe main.c -o main` → `./main`。
- **单文件**。无多文件、无自定义头文件、无外部库（仅 musl libc）、无 MIPS 交叉编译器、无 gxemul、无网络（`--network none`）。
- 源码 ≤ 65536 字节（`MAX_SOURCE_BYTES`）。
- `inputList` 非空、≤ 20 条（`MAX_CASES`），每条 ≤ 8192 字节（`MAX_INPUT_BYTES`）。
- **`runner.py:91` 把输入同时作为 stdin 和 argv**：`run_command_base + item.split()`。harness 必须忽略 argv；输入按空白分词后不得产生歧义。
- `timeLimit` 夹在 50–5000 ms，`memoryLimit` 夹在 32–512 MB。编译窗口固定 5 s。单请求总窗口 `min(30, 5 + timeLimit*cases/1000)` 秒。
- **进程非零退出 → `Runtime Error`，不是 `Wrong Answer`**。因此 harness **禁止用裸 `assert()` 判分**；必须自行判定、打印结果、`return 0`。
- 单条 stdout+stderr ≤ 65536 字节。
- 沙箱返回 `memory` 恒为 0，内存超限实际不会触发。

### C3 判题策略（`judge/strategy/DefaultJudgeStrategy.java` 实测）

### C4 跨平台可移植性（本地 MinGW gcc 8.1 ≠ 沙箱 Alpine gcc）
- MinGW-w64 是 LLP64（`long` 32 位），Linux 是 LP64（`long` 64 位）。**harness 中一切地址/页号/寄存器值一律用 `uint32_t`/`int32_t`/`uintptr_t`，禁止用 `long`/`unsigned long` 承载地址**。
- 禁止 `%zu`/`%ld` 打印指针宽度值；统一转 `unsigned` 用 `%u`，或转 `uint32_t` 用 `PRIu32`。
- 严格 C99：所有函数先声明后使用，无隐式声明（沙箱 gcc 版本更新，隐式声明会直接报错）。
- 本地验证编译命令：`gcc -std=c99 -Wall -Wextra -Werror -O2 -pipe main.c -o main`。比沙箱更严，本地过则沙箱过。
- 不依赖 `assert.h` 的中止行为、不依赖未初始化的栈值、不依赖 `int` 溢出回绕以外的未定义行为。
- **驱动 `main()` 自有的输出缓冲必须在声明处初始化**（如 `uint32_t vma[MAXS] = {0};`）。否则 gcc 无法证明学生函数会写满缓冲，`-Werror=maybe-uninitialized` 直接拒绝编译（已在 1.3 harness 上实测踩到）。
- **同一实验的各条用例，参考解输出必须互不相同**，否则验证脚本判为冗余用例。若两个场景天然同输出（如两种环都只打印 `CYCLE`），必须让驱动暴露可区分的观测量（如已构建的部分进度），而不是放宽闸门。

## 核心设计决策

### D1 判题方式：主机端等价 harness（不是代理题）

每个 Tier A 实验交付一个自包含 C99 程序，三段结构：

```
[1] 最小内核环境：MOS 真实 struct/宏定义，地址宽度改用 uint32_t
[2] 学生填写区：目标函数/宏，保留北航原始签名与语义，标注 /* finish your code here */
[3] 检查驱动 main()：从 stdin 读测试场景 → 调用学生实现 → 打印确定性可观测结果 → return 0
```

**为什么这不是代理题：** 学生写的就是 `include/queue.h` 的 `LIST_INSERT_TAIL`、`mm/pmap.c` 的 `page_alloc`、`lib/env.c` 的 `env_alloc`、`user/fork.c` 的 `duppage` —— 北航实验的原始目标函数，原始语义。检查逻辑取自工作区 `originalCode` 里**已存在的官方自检函数**（`physical_memory_manage_check()`、`page_check()`），只是把 `assert()` 改成打印判定、把固定数据改成 stdin 驱动。唯一适配是宿主环境（x86-64 + 固定宽度类型替代 MIPS 地址宽度），这一点在实验说明里如实写明。

**为什么必须 stdin 驱动：** 若只有一条空输入用例，学生直接 `printf` 期望文本即可 AC。场景由 stdin 给出、结果由学生实现算出，硬编码不可行。

**为什么禁止裸 assert：** C2 已核实非零退出 → `Runtime Error`。裸 assert 会让所有错误答案显示成「运行时错误」而非「答案错误」，误导学生。

#### D2.1 先说清楚：性能不是替换内容的理由（实测）

用户提出「2G 服务器出于性能考虑，分支把 1.1 换成极简拓扑排序或许是对的」。**实测不支持这个前提**，因此本计划按「可判题性」而非「性能」来分级。

本机 gcc 8.1.0，`gcc -std=c99 -O2 -pipe`，warm 缓存，各 2–3 次取稳定值：

| 程序 | 源码字节 | 编译耗时 | 可执行 BSS | 20 次运行总耗时 |
| --- | --- | --- | --- | --- |
| 分支风格极简拓扑排序 | 630 | 325 ms | 67 KB | 1137 ms |
| Tier A harness（2.7 规模，含 `pgtable_pool[64][1024]`） | 5069 | 345 ms | 268 KB | 1167 ms |
| Tier A harness（3.1 真实 `pmap.c` 规模） | 26121 | 360 ms | — | — |
| Tier A harness（逼近 64 KB 源码上限） | 56081 | 360 ms | — | — |

结论：
1. **源码放大 89 倍，编译耗时只从 325 ms 涨到 360 ms（+11%）**。成本几乎全是 gcc 启动 + libc 头解析，与学生代码量无关。沙箱固定 5 s 编译窗口对两者都绰绰有余。
2. **运行耗时相同**（差异 2.6%，且本机由 Windows 进程创建开销主导；Linux 沙箱内两者都是毫秒级）。
3. **内存不是瓶颈**：268 KB BSS 是 demand-zero 页，未触及不占物理内存；`--memory 512m` 是上限不是预留。分支那道「极简」题自己的 `g[128][128]` 就占 64 KB BSS，量级相同。
4. 2 GB 服务器的真实约束是 **`SANDBOX_MAX_CONCURRENT=2` 的并发闸门**（第 3 个并发请求等 30 s 后返回 503「sandbox is busy」）与 Docker 容器启动开销 —— 这两项对极简题和 harness **完全一样**。

**所以：删掉详实北航说明换不来任何性能收益，只会丢失内容。** 说明文本存在 MySQL、由前端渲染 Markdown，不进入沙箱，成本为零。

#### D2.2 Tier C 的真正理由：概念同构，且真实形态不可判题

#define LIST_INSERT_AFTER(listelm, elm, field) do { \
    LIST_NEXT((elm), field) = LIST_NEXT((listelm), field); \
    if ((LIST_NEXT((listelm), field)) != NULL) \
        LIST_NEXT((listelm), field)->field.le_prev = &LIST_NEXT((elm), field); \
    LIST_NEXT((listelm), field) = (elm); \
    (elm)->field.le_prev = &LIST_NEXT((listelm), field); \
} while (0)

        LIST_FIRST((head)) = (elm); \

        (elm)->field.le_prev = &LIST_NEXT(LIST_NEXT((elm), field), field); \

const dir = process.argv[2];
if (!dir) {
  console.error("usage: node scripts/verify-experiment-harness.mjs <experiment-dir>");
  process.exit(2);
}

const CFLAGS = ["-std=c99", "-Wall", "-Wextra", "-Werror", "-O2", "-pipe"];
const MAX_SOURCE_BYTES = 65536;
const MAX_CASES = 20;
const MAX_INPUT_BYTES = 8192;

const spec = JSON.parse(readFileSync(join(dir, "cases.json"), "utf8"));
const config = JSON.parse(readFileSync(join(dir, "judge-config.json"), "utf8"));
const variants = ["starter", "reference", "wrong"];
const work = mkdtempSync(join(tmpdir(), "oslab-harness-"));
const results = {};

function compileAndRun(variant) {
  const source = readFileSync(join(dir, `${variant}.c`), "utf8");
  const bytes = Buffer.byteLength(source, "utf8");
  if (bytes > MAX_SOURCE_BYTES) {
    throw new Error(`${variant}.c exceeds sandbox source limit: ${bytes} > ${MAX_SOURCE_BYTES}`);
  }
  const src = join(work, "main.c");
  const exe = join(work, process.platform === "win32" ? "main.exe" : "main");
  writeFileSync(src, source);
  execFileSync("gcc", [...CFLAGS, src, "-o", exe], { stdio: "pipe" });
  return spec.cases.map((c) => {
    const inputBytes = Buffer.byteLength(c.input, "utf8");
    if (inputBytes > MAX_INPUT_BYTES) {
      throw new Error(`case "${c.name}" exceeds sandbox input limit: ${inputBytes}`);
    }
    // 沙箱把 input 同时作为 argv 追加；harness 必须忽略 argv，这里一并验证。
    const argv = c.input.split(/\s+/).filter(Boolean);
    const stdout = execFileSync(exe, argv, {
      input: c.input,
      timeout: config.timeLimit,
      stdio: "pipe",
      encoding: "utf8",
    });
    return stdout;
  });
}

// 与 DefaultJudgeStrategy.normalizeOutput 完全一致的归一化。
function normalize(output) {
  return String(output ?? "")
    .replace(/\r\n/g, "\n")
    .replace(/\r/g, "\n")
    .replace(/[\t ]+(?=\n)/g, "")
    .replace(/\n+$/, "");
}

try {
  if (spec.cases.length === 0 || spec.cases.length > MAX_CASES) {
    throw new Error(`case count must be 1..${MAX_CASES}, got ${spec.cases.length}`);
  }
  for (const variant of variants) {
    results[variant] = compileAndRun(variant).map(normalize);
  }

  const expected = results.reference;
  const failures = [];

  if (new Set(expected).size !== expected.length) {
    failures.push("reference outputs are not distinct across cases; scenario coverage is too weak");
  }
  for (const variant of ["starter", "wrong"]) {
    const same = results[variant].filter((o, i) => o === expected[i]).length;
    if (same === expected.length) {
      failures.push(`${variant}.c passes every case; it does not demonstrate a detectable defect`);
    }
  }
  if (expected.some((o) => o.length === 0)) {
    failures.push("reference produced empty output for some case");
  }

  const judgeCases = spec.cases.map((c, i) => ({ input: c.input, output: expected[i] }));
  writeFileSync(join(dir, "judge-cases.json"), JSON.stringify(judgeCases, null, 2) + "\n");

  console.log(`experiment: ${dir}`);
  spec.cases.forEach((c, i) => {
    console.log(`  [${i + 1}] ${c.name}`);
    console.log(`      reference: ${JSON.stringify(expected[i])}`);
    console.log(`      starter  : ${JSON.stringify(results.starter[i])}`);
    console.log(`      wrong    : ${JSON.stringify(results.wrong[i])}`);
  });
  if (failures.length) {
    console.error("VERIFY FAILED:");
    for (const f of failures) console.error(`  - ${f}`);
    process.exit(1);
  }
  console.log("VERIFY OK: judge-cases.json written from real reference runs");
} finally {
  rmSync(work, { recursive: true, force: true });
}
```

#include <stdio.h>
#include <string.h>
#include <stdint.h>

#define BY2PG   4096u
#define PDMAP   (4u * 1024u * 1024u)
#define PTE_V   0x0001u
#define PTE_R   0x0002u
#define PTE_ADDR(pte)  ((uint32_t)(pte) & ~0xFFFu)
#define PDX(va)        (((uint32_t)(va) >> 22) & 0x3FFu)
#define PTX(va)        (((uint32_t)(va) >> 12) & 0x3FFu)
#define ROUND(a, n)    (((((uint32_t)(a)) + (n) - 1u) / (n)) * (n))
#define E_NO_MEM       4

typedef uint32_t Pde;
typedef uint32_t Pte;

struct Page { int32_t pp_ref; LIST_ENTRY(Page) pp_link; };
LIST_HEAD(Page_list, Page);

#define NPAGE_MAX 256u
#define MOS_UNUSED __attribute__((unused))
static MOS_UNUSED unsigned char phys[NPAGE_MAX * BY2PG];  /* 物理内存 arena，1MB BSS */
static MOS_UNUSED struct Page pages[NPAGE_MAX];
static MOS_UNUSED struct Page_list page_free_list;
static MOS_UNUSED uint32_t npage;
static MOS_UNUSED uint32_t freemem;
static MOS_UNUSED uint32_t maxpa;
static MOS_UNUSED Pde boot_pgdir[1024];
```

`LIST_*` 宏沿用 Task 1 已验证版本（2.1 的 reference 实现），因为后续实验依赖它们且不应让学生重复实现。

**物理内存模型（实现时确定）**：用一维字节数组 `phys[]` 模拟物理内存，**物理地址就是数组下标**，
于是 `KADDR(pa) = phys + pa`、`PADDR(kva) = kva - phys`，与真实内核线性映射语义相同，
不需要 `pgtable_pool` 这类额外池，也不需要真实指针算术。`alloc()` 在 `phys[]` 内 bump 分配。

`page2pa`/`pa2page`/`page2kva` 用 pool 索引实现，避免真实指针算术：

```c
static MOS_UNUSED uint32_t page2pa(struct Page *pp) { return (uint32_t)(pp - pages) * BY2PG; }
static MOS_UNUSED void *page2kva(struct Page *pp) { return (void *)(phys + page2pa(pp)); }
/* 越界钳位：学生写坏页表项时应判「答案错误」，不是段错误 */
static MOS_UNUSED struct Page *pa2page(uint32_t pa)
{
    uint32_t idx = pa / BY2PG;
    if (idx >= NPAGE_MAX) { idx = NPAGE_MAX - 1; }
    return &pages[idx];
}
```

**所有平台提供的 static 函数与变量必须带 `MOS_UNUSED`**，否则某实验不用其中几个就会被
`-Werror=unused-function` / `-Werror=unused-variable` 拒绝。
