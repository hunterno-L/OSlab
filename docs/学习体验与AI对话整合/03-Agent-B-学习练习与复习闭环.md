# Agent B 执行任务书：学习、练习与复习闭环

本任务书供之后执行时使用。当前交付是计划，不表示已启动实现。

## 你的目标

在现有首页、单元、题目和学习记录中完成“开始学习—按场景求助—练习/自测—继续补学或复习”的体验。你负责整组自测真正延迟判分所需的后端支持，以及普通题目的帮助与证据接线。

先完整阅读：

1. [00-双Agent协作交付计划.md](00-双Agent协作交付计划.md)
2. [01-共享契约与验收.md](01-共享契约与验收.md)
3. 仓库 `PRODUCT.md`、`DESIGN.md` 与你负责文件的当前源码。

## 必须遵守

- 图谱沿用现有显示，只改导师接线；不新增状态说明、掌握度仪表或一套图例，不改 BKT/ReviewPlanner/NextActionPlanner。
- 不做代码动画，不造不存在的递归题，不新建独立学习/复习首页，不改教师考试或任务评分规则。
- 严守主计划第 5 节文件所有权；不改 A 的聊天组件、会话 composable、AI DTO/API、公共主题或实验/节点页。
- 你的入口调用 A 的公共 `openTutor` 契约；不能复制聊天逻辑或直接调用旧 `tutorAsk` 接新功能。
- 自测不能只隐藏解析。题面、草稿、接口、统计和学习事件都必须遵守交卷前不判分/不返回结果的边界。
- 不 commit/push/部署，不改他人未提交文件，不继续派生子代理；重构建与 A 串行协调。

## 分阶段工作

### B1：D1 测评与帮助契约

- [ ] 核对 `AssessmentRun`、普通作答、事件去重、综合题、下线题和旧 run 的实际语义。
- [ ] 交付普通尝试、`TutorAssessmentGuard`、自测草稿/交卷/结果接口类型及示例，供 A 接入。
- [ ] 迁移编号交 A 统一分配；保留旧 run 默认 PRACTICE，不修改已发布迁移。
- [ ] 将前端页面所有权和后端事件/证据修改点列入本轮记录。

### B2：D2 后端真实流程

- [ ] 持久化 SELF_TEST 模式、固定题目队列/版本、草稿和不确定标记，支持版本冲突与刷新恢复。
- [ ] 草稿保存不判分、不生成学习事件、不触发推荐更新。
- [ ] 交卷验证最新草稿，服务端判分和保存结果，重复/并发交卷无重复证据。
- [ ] 未答、综合题、下线和版本失效题处理准确，统计分母解释清楚。
- [ ] 旧立即作答接口和已知解析路径不能绕过 ACTIVE 自测限制。
- [ ] 普通题提示帮助先持久化，资格在答题事务前有效；提供 A 可调用的后端守卫。

### B3：D3 练习与自测 UI

- [ ] 逐题反馈缩减为短结果与可展开解析，主操作衔接下一题，不自动呼叫 AI。
- [ ] 自测有模式选择、答题卡、上下一题、修改答案、不确定标记、保存状态与暂存退出。
- [ ] 交卷前检查未答/不确定项，失败时不丢输入，不提交旧草稿。
- [ ] 结果有逐题复盘与返回学习入口，阅读结果不新建学习事件。
- [ ] 题目求助、已看提示/答案与当前尝试绑定，接入 A 的统一导师。

### B4：D4 页面闭环

- [ ] 首页沿用现有当前单元与计划，突出一个下一步，保留简洁画像；没有数据时不造统计。
- [ ] 单元页减少重复目标/进度/建议，当前活动动作明确；选段提问与来源跳转一致。
- [ ] 头像学习入口整理到现有记录/复习位置，历史时间线可访问，不改默认登录路由。
- [ ] 资源顶栏弱化前先保证课程内入口、搜索、引用和旧链接可用，不删除资料功能。
- [ ] 实验/题目完成后的站内返回定位、保存状态和课程级刷新通知可用。
- [ ] 图谱仅接统一求助和必要定位，不新增状态说明或教学流程旁支。

### B5：D5–D7 联调与验证

- [ ] 审查 A 的面板可读性、上下文可见性、IME、草稿、滚动、历史和模型状态，问题交 A 修复。
- [ ] 按验收矩阵 B01–B09、C01–C04 做行为检查，尤其检查自测期间网络响应没有答案/解析/对错。
- [ ] 验证未答、综合题、下线、断网、双击、刷新、跨账号与跨课程，不只测试顺利答完一组题。
- [ ] 在实际已有第二课程验证相同组件，不硬编码 OS 题目和节点。
- [ ] 准备真实演示数据定位与演示步骤，不伪造题库/模型结果；协助 A 汇总交付。

## 给 A 的交接格式

写明接口/类型版本、Guard 的使用方式、所有权内实际修改文件、迁移顺序、测试命令及结果、自测未判分响应样例、交卷幂等证据、当前未完成项。验收材料不得包含学生隐私或 API Key。

## 你的完成定义

学生可以使用现有课程连续学习、按题获得反馈，也可以完成不中途泄露答案的整组自测；刷新不丢草稿，帮助资格与正式证据一致，完成后回到正确学习位置并读取真实下一步。没有新增重复仪表盘或图谱状态说明。
