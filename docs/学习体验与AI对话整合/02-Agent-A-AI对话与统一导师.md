# Agent A 执行任务书：AI 对话、统一导师与集成

本任务书供之后执行时使用。当前交付是计划，不表示已启动实现。

## 你的目标

基于现有 ZhiCore，把课程中的全局/节点/实验/单元/题目辅导整合进同一导师核心，重做可长时间使用的 AI 对话面板。参考 Codex 类对话工具的宽正文、固定输入区、简洁工具条和上下文连续性。你同时是两个开发 Agent 中的集成人。

先完整阅读：

1. [00-双Agent协作交付计划.md](00-双Agent协作交付计划.md)
2. [01-共享契约与验收.md](01-共享契约与验收.md)
3. 仓库 `PRODUCT.md`、`DESIGN.md` 与你负责文件的当前源码。

## 必须遵守

- 图谱不增加状态说明，不改掌握度/复习算法，不做代码动画，不新建重复学习系统。
- 严守主计划第 5 节的文件所有权。B 拥有题卡、首页、单元、图谱页接线、练习与测评、普通尝试/帮助服务；你提供公共能力，不直接改他的文件。
- `FloatingAiAssistant.vue` 已有用户未提交的头像和拖动改动，先保存差异清单再修改。不能恢复到 Git 版本抹掉它们。
- 不 commit/push/部署，不覆盖他人工作；不新加大型依赖或中间件，不继续派生子代理。
- 模型/工具预算、鉴权、来源、FALLBACK、净化渲染、自定义模型配置和课程隔离保持有效。
- 以实际接口支撑 UI；没有生成流就不用假打字，没有取消能力就不显示停止按钮。

## 分阶段工作

### A1：D1 基线、入口与接口

- [ ] 建立 `artifacts/learning-ai-ux/baseline.md`、`ownership.md` 和简短资源占用记录，只新增本轮目录。
- [ ] 记录前后端已有检查结果与未提交差异，确认迁移编号；不沿用旧台账“全绿”的暗示。
- [ ] 交付 `openTutor`、场景/意图/上下文类型及旧调用适配，供 B 接入。
- [ ] 与 B 对齐 `TutorAssessmentGuard`、attemptContextId、评估 runId、完成通知和返回定位。
- [ ] 将侧栏、展开模式、消息排版和输入状态落实为明确的实现范围；不生成独立原型交差。

### A2：D2 历史、追问与状态

- [ ] 补课程会话列表和轮次分页查询，使用真实持久数据；权限与课程限定有行为测试。
- [ ] 后端对最近成功轮次做有限长度读取，为模型提供多轮语境；无需额外摘要调用。
- [ ] 按用户/课程/会话管理消息、草稿和请求身份，处理跨课程迟到响应、刷新恢复、历史分页去重。
- [ ] 网络未定状态复用 requestId 恢复轮次；明确失败后的重试为新尝试，不能重复用户气泡或后台无限重试。

### A3：D3 面板核心

- [ ] 实现侧边辅导、展开阅读与窄屏全屏，三者共用一个消息核心；关闭不丢任务。
- [ ] 重做正文、代码、来源、工具详情、下一步行动的层级，减少多重卡片和调试信息。
- [ ] 完成自增长 composer、IME、等待中编辑、复制、草稿保护、自动滚动阈值与新消息提示。
- [ ] 完成最近对话、明确的新话题行为和测试后模型选择；当前请求与下一轮模型切换不混淆。

### A4：D4 场景迁移

- [ ] 迁移节点与实验页的独立导师，去掉新请求继续走旧本地消息分支的情况，旧后端接口保留兼容。
- [ ] 旧本地历史不自动上传为可信服务端对话，不擅自删除；如保留入口，标注为只读旧记录。
- [ ] 实验只携带用户明确选择的代码/报错及可信结果定位，不自动抓全文。
- [ ] B 的单元/题卡/图谱入口均可带上下文打开同一导师，页面切换只改变下一轮范围。
- [ ] 题目辅导先调用 B 的后端守卫记录帮助和校验自测限制，再调用模型。

### A5：D5–D7 审查、联调与交付

- [ ] 审查 B 的草稿、提交、答案可见性、权限和幂等，问题交 B 修复，不抢写文件。
- [ ] 按验收矩阵 A01–A09、C01–C04 验证；和 B 完成题目提示/自测限制联调。
- [ ] 拍并打开检查桌面/窄屏真实运行截图；修复 composer 遮挡、长内容溢出、焦点和滚动缺陷。
- [ ] 串行安排前端/后端检查，标明基线失败、未运行与新失败。
- [ ] 整理 B 的交付、README 必要修改、最终验收记录与演示脚本；不用静态效果图或 Mock 宣布完成。

## 给 B 的交接格式

每次交接只需写清：可用导出/接口和版本、实际修改文件、可调用样例、完成检查、已知限制、下一步需要 B 配合的事项。契约有变先更新主契约再通知 B，不让 B 从代码 diff 猜变更。

## 你的完成定义

学生可以从任意已约定场景打开清楚、美观的导师面板，连贯追问，切页/刷新后保留真实会话，阅读来源和执行下一步；课程和账号隔离、帮助资格、重试幂等都可证实。界面更好看与真实对话能力必须一起完成。
