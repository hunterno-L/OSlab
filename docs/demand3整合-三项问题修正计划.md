# demand3 三项问题修正计划

日期：2026-10-22
范围：仅修正用户反馈的三项问题，不改变已完成的课程/任务/图谱产品逻辑；不部署、不提交、不推送。

## 1. 问题与根因

### 1.1 打开“关系标签”后关系不显示

当前实现（`src/components/KnowledgeGraph.vue`）：

- `computeRelationLabelIndexes` 先判断 `ctx.labelsVisible`，而该值绑定节点文字阈值 `NODE_LABEL_MIN_ZOOM = 0.72`。较大课程的默认适配缩放通常低于 0.72，导致关系标签被整体跳过。
- 即使缩放高于阈值，代码仍丢弃长度 `< 170` 的边；确定性网格中相邻节点间距约 140/50，绝大多数边都小于 170，因此开启开关仍几乎无标签。
- 边标签固定放在边中点，紧凑节点之间可能压住节点；当前避让只检查标签之间和“非端点节点”。

### 1.2 需要真实代码联动，而不是伪代码联动

当前 `src/simulation/codeMaps.ts` 的 `lines` 是手写伪代码，播放器标题与说明也明确标注“算法伪代码”。用户要求展示项目真实实现代码，并继续按步骤高亮。

### 1.3 学生“学习记录”打开报“系统错误”

最可能原因（按优先级）：

1. 新增活动查询依赖 `learning_activity_record` 表；本地存量数据库尚未应用 `oslab_upgrade_v9_learning_activities.sql`，`/api/learning/records/activities` 查询该表时抛 SQL 异常，被全局异常处理为“系统错误”。
2. 后端仍在运行旧 jar/旧进程，没有新 `/learning/records/activities` 路由，前端收到 404/500。
3. 前端只展示全局错误，没有降级到既有 `/learning/mastery/timeline`，因此整页不可用。

## 2. 修正方案

### 2.1 图谱关系标签

1. 关系标签可见性与节点标签解耦：
   - 节点文字阈值保持 0.72；
   - 关系标签最小缩放改为 0.25；选中/悬停邻边在开关开启时始终优先显示。
2. 移除“边长度 < 170 全部丢弃”的硬阈值，改为按缩放后的标签尺寸与节点矩形做避让；短边允许标签上移（`offset: [0, -8]`），避免压住节点。
3. 当无选中/悬停时，在最小缩放以上显示数量受限的非冲突标签（默认 12–18 条）；放大后上限提高。
4. 开关、选中、悬停、缩放层级变化都只刷新视觉，不重置视野。
5. 回归测试：
   - 开启开关且存在选中节点时至少一条关系边 `label.show === true`；
   - 关闭开关后所有关系边 `label.show === false`；
   - 150 节点默认适配下开启开关能出现部分标签；
   - 缩放低于节点标签阈值时，选中邻边标签仍可显示。

### 2.2 真实代码联动

1. 将 `CODE_MAPS` 的 `lines` 从伪代码替换为项目真实 TypeScript 实现摘录，并新增 `sourceFile`、`symbol` 元数据（如 `src/simulation/cpu.ts` / `fcfs`）。
2. 代码面板改为“算法实现（TypeScript 源码摘录）”，显示文件路径与“真实实现”标识；保留现有事件→行映射和行高亮。
3. 核心实现摘录必须来自实际算法文件：
   - CPU：`fcfs/sjf/hrrn/priorityNonPreemptive/priorityPreemptive/roundRobin/mlfq`
   - 分配：`chooseFreeBlock` 各分支 + `runAllocation` 核心循环
   - 页面：`runPage` 的 FIFO/LRU/OPT 分支
   - 磁盘：`fcfsActions/sstfActions/scanActions/cscanActions`
4. 新增测试：对 18 项逐项校验展示的每一行（去空白后）确实出现在声明的源文件中；非源码行不得进入面板。
5. 更新播放器、SimulationView 和交付文档中的“伪代码”措辞。

### 2.3 学习记录“系统错误”

1. 后端增加幂等建表初始化器：启动时执行 `CREATE TABLE IF NOT EXISTS learning_activity_record (...)`；失败只记录警告，不阻止应用启动。保留 v9 SQL 作为正式迁移。
2. `runActivities` 对活动记录表查询增加 `DataAccessException` 容错：表缺失/权限不足时返回空运行记录，仍返回题目、判题、任务和单元活动，避免整页 500。
3. 前端活动查询失败时降级到既有 `/learning/mastery/timeline`，以事件卡片展示并提示“活动记录接口暂不可用，已回退到事件时间线”，不再整页报系统错误。
4. 增加后端单元测试：模拟活动记录 Mapper 抛 `BadSqlGrammarException`，其余来源仍返回且不抛出。
5. 交付说明补充：存量库可手动应用 v9；后端需重新构建/重启才能加载新路由。
