# 实验维护包 · 导入与校验说明

这批交付把 41 道编程实验的**题面 / 起始代码 / 参考解 / 判题用例 / 判题配置**整理成平台可导入的
`oslab-experiment-maintenance/1.0` 包。

```
content/operating-systems/wangdao-2025/experiments/
├─ A-第一章-实验维护-001/   （5 个）
├─ A-第二章-实验维护-001/   （7 个）
├─ A-第三章-实验维护-001/   （13 个）
├─ A-第四章-实验维护-001/   （15 个）
└─ 导入说明.md
```

每个包：

```
experiment-maintenance.json
experiment-files/<questionId>/
  content.md          题面（含输入/输出格式与样例）
  starter.c           起始代码（TODO 骨架）
  reference.c         参考实现
  judge-cases.json    [{input, output}]
  judge-config.json   {timeLimit, memoryLimit, stackLimit}
  wrong.c             典型错误解（必须判 Wrong Answer）
交接说明.md
```

`sectionCode` 取课程章节：第一章 `sec.overview`、第二章 `sec.memory`、
第三/四章 `sec.process`。

## 前提

1. 后端已启动（默认 `http://127.0.0.1:8121/api`），数据库已初始化。
2. 有**管理员**账号。
3. 节点补丁已执行（否则导入报 `未知 nodeCode`）。

### 节点补丁

`数据库文件/oslab_upgrade_v11_experiment_nodes.sql` 做四件事：

- 注册 15 个核心知识节点（`os.memory`、`os.process` 等）
- 软删 7 条历史垃圾/重复实验（含章节映射）
- 修正历史导入造成的课程名乱码（仅在仍为乱码时改写）
- 补齐演示账号昵称（仅空值时）

**Docker 部署**：`deploy/docker-compose.yml` 已挂载该文件，
`deploy/mysql-init/10-load-oslab-db.sh` 会在 v3–v10 之后自动执行，无需手工操作。

**手动部署**：

```bash
mysql -uroot -p --default-character-set=utf8mb4 oslab_db \
  < 数据库文件/oslab_upgrade_v11_experiment_nodes.sql
```

全部语句幂等，可重复执行。

## 离线校验（不需要后端）

`scripts/verify-experiment-packages.mjs` 会：

- 校验包结构、附件是否齐全、`judgeCase` / `judgeConfig` 是否合法
- 编译 `reference.c`，逐条跑用例，输出必须与期望一致
- 编译 `wrong.c`，必须至少有一条用例失败

```bash
# gcc 不在 PATH 时指定完整路径
OSLAB_GCC=/usr/bin/gcc node scripts/verify-experiment-packages.mjs \
  content/operating-systems/wangdao-2025/experiments
```

当前结果：4 个包、40 个实验全部通过。

## 导入

`scripts/import-experiment-package.mjs` 完成
`login → preview → commit → review(SUBMIT → APPROVE → APPLY)`，支持传父目录批量导入：

```bash
# 先只校验
node scripts/import-experiment-package.mjs \
  content/operating-systems/wangdao-2025/experiments \
  http://127.0.0.1:8121/api <管理员账号> <口令> --dry-run

# 正式导入（已 APPLIED 的实验自动跳过）
node scripts/import-experiment-package.mjs \
  content/operating-systems/wangdao-2025/experiments \
  http://127.0.0.1:8121/api <管理员账号> <口令>
```

## 验证

1. `编程实验` 页能搜到对应实验，标题与关联节点正常。
2. 打开实验，题面与起始代码正常显示。
3. 用参考解提交，判题结果为 `Accepted`。
4. 数据库侧：

```sql
SELECT COUNT(*) FROM experiment_revision WHERE reviewStatus='APPLIED';
SELECT COUNT(*) FROM course_resource WHERE resourceType='EXPERIMENT';
SELECT COUNT(*) FROM experiment_node;
```

## 边界

- 起始代码：第一/三/四章为通用 TODO 骨架，第二章 2.1–2.8 为按题骨架；判题编译单个
  `main.c` 并比对标准输出，不是内核工程构建。
- 判题标准：`judgeCase.input` 喂 stdin，`judgeCase.output` 与 stdout 归一化后做字符串比对。
- `nodeMappings` 使用 v11 的 `os.*` 节点；正式课程若已有 J 的知识包节点，可替换为对应 `nodeCode`。
- 本批不改标题与历史 ID；回滚可用 `experiment_revision.beforeJson`。
