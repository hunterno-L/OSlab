# 实验 1.4 深入理解 MIPS 汇编与 C 语言的交互

## 实验背景

在本实验中，你将通过分析和编写代码，深入理解 MIPS 汇编语言与 C 语言之间的交互关系。你将学习如何将 C 语言代码编译成 MIPS 汇编代码，并理解函数调用、循环结构和条件判断在汇编层面的实现。

C 代码不会自己跑起来：必须有人先把栈指针设好，`jal main` 才有意义。本实验先看 `fib` 递归与 `main` 循环被交叉编译器翻译成什么指令，再亲手补 `boot/start.S`，让内核从上电的第一条指令走到 C 世界。

## 知识要点

1. **MIPS 汇编基础**：
   - 理解 MIPS 汇编的基本指令和寻址模式。
   - 学习如何从 C 代码生成 MIPS 汇编代码。
2. **函数调用与返回**：
   - 理解函数调用过程中的栈操作，包括参数传递和返回值处理。
   - 学习函数调用的汇编实现，包括压栈（push）和弹栈（pop）操作。
3. **循环与条件判断**：
   - 理解循环结构在汇编层面的实现，包括 `goto` 和条件跳转指令。
   - 学习条件判断的汇编实现，包括 `slti` 和 `bnez` 指令。
4. **C 语言与汇编的对应关系**：
   - 理解 C 语言中的高级结构（如循环、条件判断、函数调用）在汇编层面的对应实现。
   - 学习如何通过汇编代码理解 C 代码的执行流程。

**扩写（MIPS o32 公开约定）**：`jal` 把返回地址写进 `$ra` 并跳转，`jr $ra` 返回；递归函数必须把 `$ra` 与 `$fp` 压栈，否则第二层调用会覆盖返回地址。`$a0–$a3` 传前 4 个参数，第 5 个及以后走栈；`$v0` 存返回值。`slti`+`bnez`/`beq` 是 C 的 `if`/`for` 条件在汇编层的形态。`$sp` 必须指向合法可写内存（`bootstacktop`），MIPS 栈向下生长。

   - 观察编译后的汇编代码，理解 C 代码与汇编代码的对应关系。
3. **分析汇编代码**：
   - 分析汇编代码中的函数调用、循环结构和条件判断。
   - 理解汇编代码中的栈操作和跳转指令。
4. **完成指定的汇编代码编写**：
   - 根据实验要求，完成 `boot/start.S` 文件中缺失的部分。
   - 设置栈指针并跳转到 `main` 函数。

**每步验证**：步骤 1 能说出 fib 递归深度与栈帧大小的关系；步骤 2 用 `-S -O0` 与 `-O2` 各出一份汇编并对比优化对栈操作的影响；步骤 3 标注 `jal`/`jr`/`slti`/`bnez`/`sw`/`lw`；步骤 4 补全 `boot/start.S`，`make` 后 gxemul 能打出 `main` 的输出。

## 常见错误

1. 不设 `$sp` 就 `jal main`：C 函数一压栈就踩到未初始化内存，gxemul 立刻异常或无输出。
2. `jal` 后不填延迟槽 `nop`：延迟槽里的指令会被执行，可能把刚设好的寄存器改坏。
3. 递归函数不保存 `$ra`：`fib` 第二层调用覆盖返回地址，`jr $ra` 跳回错误位置。
4. 用宿主 x86 gcc 生成的汇编冒充 MIPS 汇编：调用约定、寄存器名、延迟槽语义全都不同，观察结论无效。
