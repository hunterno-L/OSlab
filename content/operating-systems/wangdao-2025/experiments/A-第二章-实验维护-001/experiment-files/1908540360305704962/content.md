### 任务描述

`boot_map_segment()` 把一段连续的虚拟地址映射到连续的物理地址，粒度为 4KB 页。给定 `va_start`、`size`、`pa_start`，逐页输出映射关系。

### 输入格式

一行三个整数 `va_start size pa_start`（十进制，字节）。

### 输出格式

若 `size <= 0`、`size` 不是 4096 的倍数，或 `va_start`/`pa_start` 未按 4096 对齐，输出 `INVALID`。

否则每页一行：`<虚拟地址> <物理地址>`，从起始地址开始逐页递增。

### 样例

输入：

```
4096 8192 32768
```

输出：

```
4096 32768
8192 36864
```
