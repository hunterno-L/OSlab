# 后端并行协作边界（即时契约）

课程 agent 当前实现位于 `com.yupi.springbootinit.course`。接口完整形状见 09。

## identity agent 需要的 v7

课程导入器直接使用 JdbcTemplate 下列列名，请 v7 使用相同列名：

- `knowledge_node_registry(id,nodeCode UNIQUE,name,nodeType,description,aliasesJson,homeSectionCode,sourceRefsJson,layer,createTime,updateTime,isDelete)`。
- `knowledge_node_relation(id,fromNodeCode,toNodeCode,relationType,reason,sourceRefJson,createTime,updateTime,isDelete)`，fromNodeCode/toNodeCode/relationType 唯一。
- `learning_question.questionCode`，`learning_attempt.sourceUnitCode/sourceActivityCode`，`question_submit.sourceUnitCode/sourceActivityCode`。课程 complete 查询会验证这四项上下文及 userId/匹配真实题目。

`CourseService.complete(String activityCode, JsonNode request, long userId)` 是公开服务接口。
题目完成传 `{attemptId:"..."}`，实验完成传 `{submissionId:"..."}`，请在真实判分后调用，或让前端调用 complete；同一进度 upsert 幂等。
`CourseContentService.saveUnit(String unitCode, JsonNode request, long userId)` 创建/修改完整单元草稿；保留已发布快照。实验映射修改活动可先 `manage("units",unitCode)` 得草稿，再 saveUnit 写回；必需 courseCode/objectives/nodeMappings/activities 字段。

v6 的 `course_resource` 是实验资源登记点：id/resourceCode/resourceType/title/questionId/adapterKey/algorithmKey/status/metadataJson。请实验维护工具 upsert 该表；需可用实验才 status=PUBLISHED。已有单元编辑草稿位于 learning_unit.draftJson，learning_unit_activity 是草稿索引，学生始终读 publishedJson。

课程模块已实现 `CourseGraphSyncService`：知识导入写持久化同步队列，关系库提交后同步 Neo4j；失败保留 PENDING。显式 `knowledge_node_legacy_identity` 绑定的节点沿用 name，仅写 displayName，不按相似名称自动合并。管理员 `POST /api/teaching/content/graph-sync` 重试。
