# 课程接口契约（已实现并完成本地验证）

统一返回现有 `{code:0,data:...,message:"ok"}`；所有接口登录，`/teaching` 管理员。
学生接口只读取已发布单元／教学块。数据库雪花 ID 一律 JSON 字符串。

## 学生

- GET `/api/courses` → `[{courseCode,title,description,status,publishedUnitCount,completedUnitCount,progressPercent}]`。课程目录存在但无发布内容时 status=`AWAITING_CONTENT`。
- GET `/api/courses/{courseCode}/outline` → `{courseCode,title,sections:[{sectionCode,parentSectionCode,title,textbookNumber,sectionType,sortOrder,children,units}],progress}`；units 为扁平单元摘要 `{unitCode,sectionCode,title,sortOrder,estimatedMinutes,progress}`，progress=`{status,goalStatus,requiredCount,completedCount,percent}`。
- GET `/api/courses/{courseCode}/resume` → `{courseCode,unitCode,activityCode,reason}`；reason=`AWAITING_CONTENT / FIRST_UNIT / CONTINUE / COURSE_COMPLETED`，无内容时两个代码 null。
- GET `/api/courses/units/{unitCode}` → `{unitCode,courseCode,sectionCode,title,objectives,estimatedMinutes,revision,nodeMappings,activities,progress,previousUnitCode,nextUnitCode}`。
- activity → `{activityCode,title,activityType,sortOrder,required,reference:{kind,code},config,completionRule,completed,passed,content?}`；CHUNK 的 content=`{chunkCode,title,chunkType,contentMd,sourceRef,assets,revision}`；QUESTION 仅 reference/questionId，不含答案，请复用现有题目详情和作答接口。
- POST `/api/courses/activities/{activityCode}/complete` 请求 `{sourceUnitCode,mode?:"MAINLINE"|"REVIEW",confirmed?:true,runToEnd?:true,attemptId?:"...",submissionId?:"..."}` → 单元 progress 加 `{activityCode,completed,passed,completionRule}`。阅读和演示仅记进度；题目／实验必须提供属于本人、匹配资源和活动上下文的真实结果，禁止 correct/pass 布尔声明。判题平台故障不写完成或未达标结果。
- GET `/api/courses/nodes/{nodeCode}/units` → 已发布单元摘要数组。

## 管理员

- GET/PUT `/api/teaching/courses/{courseCode}/outline`；PUT `{title,description,sections:[协作目录结构]}`（仅修改传入项，不删除未传入目录）。
- GET/PUT `/api/teaching/units/{unitCode}`；PUT 协作单元对象加 courseCode，保存草稿并保留发布快照。GET 返回编辑草稿及 revision/status。
- POST `/api/teaching/units/{unitCode}/publish`：校验所有引用已发布；仅 APPROVED 草稿可发布。
- POST `/api/teaching/content/{entityType}/{entityCode}/review`：entityType=`chunks/units`，请求 `{action:"SUBMIT|APPROVE|REJECT|PUBLISH",reason?}`；保留操作者审核记录。
- POST `/api/teaching/content/import/preview|commit`：接收 `{package:协作KNOWLEDGE或UNITS对象, assets:[{path,contentBase64,contentType}]}`。也接收 `{content:"协作包JSON文本",assets:[...]}`，不用压缩包解析。图片仅 PNG/JPEG/WebP/GIF，受总大小／路径检查，保存批次前缀后重写 Markdown 路径。成员继续只交 JSON＋assets 文件，L 的管理页代上传。
- 导入返回 `{valid,items:[{type,code,action}],errors:[{path,message}],created,updated,unchanged}`；commit 再次完整校验。所有导入先入 DRAFT；稳定代码沿用 ID，无变化不增 revision，修改已发表内容保留当前学生发布快照。

编程实验／题目导入接口由身份与测评集成模块提供，保持其独立入口。课程表 v6 与稳定身份 v7 必须一起迁移后使用。

补充管理接口：GET `/api/teaching/content/catalog` 查看来源／词表／教学块／资源；GET `/api/teaching/content/chunks/{chunkCode}` 读取草稿；PUT `/api/teaching/content/sources/{sourceCode}` 登记实际来源；PUT `/api/teaching/content/resources/{resourceCode}` 更新已登记资源的 status/adapterKey/algorithmKey。DEMO 启用只接受已实现适配器 page.FIFO/page.LRU/page.OPT/cpu.FCFS/cpu.SJF/cpu.RR，必须明确 `runtimeVerified:true`。18 项登记默认均为 DRAFT，未宣称完成适配。

知识导入提交保存图谱同步队列；提交后尝试同步，失败保持 PENDING。POST `/api/teaching/content/graph-sync` 重试，返回 status/pendingCount。关系库草稿导入成功与 Neo4j 可用性分开记录。

初始化 SQL 只登记真实五章目录、来源、第一章十个空活动草稿及 18 个演示草稿。没有教材正文或学生可见的伪发布单元。协议样例／TOC 块不可作为正式正文发布。

## 集成补充（2026-10-17）

- POST `/api/courses/units/{unitCode}/position` 请求 `{activityCode,mode:"MAINLINE"|"REVIEW"}`，保存选中活动（未完成也可恢复）。返回 `{unitCode,activityCode,mode,mainlineUpdated}`。复习、已完成单元、倒退到更早单元均不覆盖主线继续位置。GET 单元不再修改位置；前端选中活动时调用 position。复习链接请带 mode=REVIEW。
- complete 请求现在**必填 sourceUnitCode**；返回原 progress 字段加 `{activityCode,completed,passed,completionRule}`。SUBMIT 错误仍可 completed=true/passed=false；PASS 错误 completed=false/passed=false。两者都不给阅读生成掌握事件。mode 可传 REVIEW；显式定位过的单元沿用已存 mode。
- 单元 resource 新增 `resourceConfig`，只下发 metadata.resourceConfig，不下发实验维护资料／参考答案。
- 管理员 GET `/api/teaching/content/catalog` 返回 sources（已解析对象）、nodes、chunks、units、resources（含metadata/resourceConfig）、graphSync。GET/PUT `/api/teaching/content/sources/{sourceCode}`；GET/PUT `/api/teaching/content/nodes/{nodeCode}`（PUT 完整节点加courseCode，经过知识导入校验）；GET/PUT `/api/teaching/content/resources/{resourceCode}` 查看／启用已登记资源。
- GET `/api/teaching/content/graph-sync` 返回 `{status,pendingCount,graphAvailable,constraintReady,runs}`；status=SYNCED/PENDING/NOT_READY。POST 同路由重试并建立 Neo4j nodeCode 唯一约束。发布教学块及单元必须确认相关节点同步完成。新节点 chapter 为顶层章节中文名，homeSectionCode 保留精确定位，label 按基础／进阶／应用兼容现图谱。
- 资源 PUT 支持 resourceConfig（对象）、runtimeVerified、status、adapterKey、algorithmKey；只允许资源与适配器匹配。课程初始化装载现为原六项后依次 v6、v7，既有数据卷仍需显式执行增量迁移，不运行重建。
- 同正文新批次重导时，附件相同保持原已归档引用；图片变化创建新草稿修订指向新批次。当前 publishedJson 始终保留原引用直到审核发布。
- EXPERIMENT 资源启用需已有 `APPLIED` 修订并明确 `runtimeVerified:true`。原有独立编程实验继续沿用原 questionId；导入维护包仅保存修订草稿。
- 题目图片支持内容哈希地址 `/api/courses/assets/hash/{sha256}`；题面／选项随题目发布开放，解析图根据本人作答解析记录开放。教材块继续使用 `/api/courses/assets/{assetId}`。
- 本地验证记录、运行库迁移情况及剩余内容工作见 [L 系统实施与接收说明](12-L系统实施与接收说明.md)。
